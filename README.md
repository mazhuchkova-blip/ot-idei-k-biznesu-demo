# От идеи к бизнесу

Бесплатный демонстрационный прототип приложения, которое помогает пройти путь от исходной идеи до первого плана проверки.

## Что работает

- два сценария старта: с готовой идеей или с подбором направления;
- маршруты по этапам «Идея», «Клиент», «Модель», «План»;
- сохранение ответов в браузере;
- итоговая сводка и копирование плана;
- адаптивная версия для телефона и компьютера.

## Запуск

Откройте `index.html` в браузере. Для публикации используется GitHub Pages из корня ветки `main`.

Это бесплатная демонстрационная версия. Платежей, регистрации и личных кабинетов нет.
